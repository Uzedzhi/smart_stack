# Stack on C

Быстрая и безопасная структура стека на Си. Умеет работать с тремя данными в стеке, достаточно при компиляции задефайнить макрос, соответствующий своему типу:
  - строки (макрос _STK_STR_TYPE)
  - числа с плавающей точкой (макрос _STK_FLT_TYPE)
  - целые числа (выбран по умолчанию, можно ничего не писать)

Также присутствуют три режимы проверки ошибок от 0 до 3:
 - 0 уровень: без проверок, максимально быстро, но также не безопасно(например pop в пустом стеке вызовет ошибку)
 - 1 уровень: минимальные проверки, уже безопасно
 - 2 уровень: добавляется канареечная защита
 - 3 уровень: добавляется защита при помощи хеша.

В любой момент в программе пользователь может вызвать функцию `stackdump` для графического просмотра состояния стека и всех ошибок, которые могут в нем быть. Снизу представлена иллюстрации данного дампа:
